Frequently Asked Questions

What is the difference between CasperPortal and CasperB2B?

CasperPortal is the software platform — the CRM and automation system. CasperB2B is a separate agency that provides optional done-for-you setup of that software.

Do I have to use CasperB2B to use CasperPortal?

No. CasperPortal is available as a self-serve subscription at $297/month with a 14-day free trial. Done-for-you setup is only for businesses that want the technical setup handled for them.

How much does done-for-you CRM setup cost?

There are two options: $399/month plus a $1,500 one-time setup fee, or $199/month plus a $3,500 one-time setup fee. Both include full CasperPortal platform access.

Can I start self-serve and switch to done-for-you later?

Yes. You can start on the self-serve plan and add a done-for-you implementation later if you decide you want the setup handled for you.
